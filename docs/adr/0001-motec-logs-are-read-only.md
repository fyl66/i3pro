# MoTeC 日志只读，用户改动写进侧车文件

MoTeC 的 `.ld`/`.ldx` 是私有格式，i2 Pro 把用户改动（信标、本地数学）写回旁边的 `.ldx`。
i3pro 决定**不写任何 MoTeC 格式**：`.ld` 永远只读，用户的切圈改动写进同名的
`<场次>.laps.json`。理由是要复刻 `.ldx` 的私有结构就得跟着 MoTeC 的版本走，而一个能 diff、
能进 git、能被分享链接带上的 JSON 便宜得多。代价是 i2 Pro 读不到我们放的**信标**，
互通只能靠导出（CSV / 快照）。

## Considered Options

- **写回 `.ldx`**（i2 Pro 的做法）：能与底盘组的老工作区双向互通，但要复刻私有的
  XML 结构与哈希字段，且每次 i2 升级都可能失效。收益只落在少数继续用 i2 的人身上。
- **塞进 Parquet 元数据**：省一个文件，但用户改动会被当成缓存的一部分被清掉，
  而"缓存"和"用户资产"必须能分开删除。
