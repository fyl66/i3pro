# 前端是一个无构建步骤的单文件 HTML，且不引入运行期依赖

工作台（`src/i3pro/web/viewer.html`）必须同时在三种条件下工作：试车现场没有网络、
队友的笔记本上不一定装了 Node、接手的人可能只会 Python。因此不用 React / uPlot / 打包器——
波形是手写 Canvas，交互是原生 ES 模块，整个前端是一个可以邮件发出的文件。换来的代价是
布局系统、图表引擎、离屏缓存都要自己写（前端约 1500 行），但保住了"双击即开、离网可用、零安装"。

## Considered Options

- **React + uPlot + Vite**：省掉图表与交互的编写量，但引入几百 MB 的 `node_modules`、
  一个构建步骤，以及一个明年可能没人会升级的依赖树；离线与"发一个文件给队友"都保不住。
- **uPlot，不打包**（把库 vendor 进来）：保住单文件，但 342–437 通道的等比降采样、
  双光标联动、距离轴对齐仍然要自己写，省下的只是坐标轴绘制。
- **Streamlit / Plotly**：一周内能出原型，但双光标联动、缩放性能、URL 分享都不达标。
