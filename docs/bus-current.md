# 母线电流怎么从电机电流算出来（实测）

**问题**（2026-10 之前一直回答不了）：`i_data`（IVT 测的母线电流）与四条电机的
`TorqueCurrent` 有什么数学关系？能不能用电机电流推算母线电流？

**为什么以前回答不了**：这两个量从来不在同一份文件里——C125 的 `.ld` 有电机通道但没有
IVT，记录仪的帧表有 `I_Data` 但没有电机通道。`i3pro pair` 把两边合成同一个场次之后才有
得算（见 [A76](ACCEPTANCE.md)）。本文的每个数字都由 `python tools\bus_current.py` 跑出来。

## 一句话结论

**能用电机电流推算，但必须带上转速**——母线电流由功率决定，而同样的电流在低速时从电池
抽的少得多。只看电流那条式子能给出量级，误差是功率法的 2.7 倍。

## 符号约定（先看这个，不然公式全反）

驱动时 `I Data` 是**负的**：`20261005-底马八字` 是 −84.12 … 0.01 A，`jhy高避` 是
−152.69 … 74.15 A（上界为正，出现在回充那几秒）。也就是说 **`I Data` 的"放电 = 负、
回充 = 正"**，与通常"放电为正"的习惯相反。下面所有公式都按这个记录仪的约定写。

## 数据

17 场同时有母线 + 四条电机（`i2pro_data` 里 `I Data` / `U1 Data` /
`MCU1 FR、MCU2 FL、MCU3 RL、MCU4 RR TorqueCurrent` 都齐的那些）；参与拟合的样本
**1,388,976** 个（母线电压 > 100 V 的格子，整段为 0 的电压格是没上电/采样缺失，先掩掉）。

## 电机常数

`T = kt·i_q`（过原点，只取 |i_q| > 5 A 的样本）——四个电机是同一种：

| 轮 | kt (Nm/A) | R² | 样本 |
| --- | --- | --- | --- |
| FR | 0.2419 | 0.9974 | 260,249 |
| FL | 0.2414 | 0.9943 | 267,047 |
| RL | 0.2417 | 0.9966 | 272,383 |
| RR | 0.2414 | 0.9925 | 273,597 |

平均 **kt = 0.2416 Nm/A**。扭矩通道（`AMK* ActualTorqueValue`）与电流通道线性得几乎完美，
所以两条公式可以互相换算。

## 公式 B（推荐）：带上转速与母线电压

```
I_bus = -(1/η)·Σ(T_m·ω_m)/U_bus + b
```

实测 **1/η = 1.312（η = 0.762）、b = −1.207 A**，
**R² = 0.9813、RMS = 2.25 A**（n = 1,388,976）。

改成"只用电流和转速"的写法（`T = kt·i_q`，ω = rpm × 2π/60）：

```
I_bus = -0.3169·Σ(i_q,m·ω_m)/U_bus - 1.207
```

`-0.3169 = -kt/η`，与上面那条是同一件事。

## 公式 A（只有电机电流）

```
I_bus = -0.5521·Σi_q - 0.523
```

实测 **R² = 0.8673、RMS = 6.01 A**（同一批样本）。逐场 R² 在 0.34–0.94 之间。

| 模型 | R² | RMS |
| --- | --- | --- |
| B：功率法（要转速 + 母线电压） | **0.9813** | **2.25 A** |
| A：只看电流 | 0.8673 | 6.01 A |

**为什么 A 差这么多**：母线电流量的是**功率**（`I = P/U`），而功率 = 扭矩 × 转速。
两台车用同样的电流，转速差一倍，母线电流就差近一倍——A 式把这一项整个丢了。

## 直接用：两条能贴进 i3pro「数学通道」的表达式

实测（本机跑 `out\_bus_maths.py`，与 `I Data` 逐点比）：

| 场次 | 功率法 R² / RMS | 电流法 R² / RMS |
| --- | --- | --- |
| `20261005-底马八字` | 0.9082 / 3.06 A | 0.7159 / 5.38 A |
| `cjh高避1` | 0.9962 / 1.70 A | 0.8579 / 10.41 A |

```
母线电流_功率法 = -1.3116*(AMKFR ActualTorqueValue*MCU1 FR ActualVelocity + AMKFL ActualTorqueValue*MCU2 FL ActualVelocity + AMKRL ActualTorqueValue*MCU3 RL ActualVelocity + AMKRR ActualTorqueValue*MCU4 RR ActualVelocity)*0.1047197551/U1 Data - 1.207
母线电流_电流法 = -0.5521*(MCU1 FR TorqueCurrent + MCU2 FL TorqueCurrent + MCU3 RL TorqueCurrent + MCU4 RR TorqueCurrent) - 0.523
```

`0.1047197551 = 2π/60`（数学引擎里没有 `pi` 常量，所以写成字面量）。

## 已知边界（照着公式用之前先看这几条）

* **瞬态上会差很多**：`20261005-底马八字` 上最大偏差 **76.2 A**。RMS 只有 3 A 是因为
  大偏差集中在少数冲击样本上；拿它做能耗积分可以，拿它逐点对波形不行。
* **三场拟合明显更差**（R² 0.90–0.91：`底马八字`、`传杰八字`、`cjh阶跃+脉冲`）。
  这三场里前后电机的最高转速差得离谱（`底马八字` 里 FR 7248 rpm、RR 16518 rpm），
  怀疑那几场的 `ActualVelocity` 通道本身有问题——**没有查证，只是标记**。
* **η = 0.762 是整条传动链的等效值**（逆变器 + 电机 + 减速箱 + 轮胎），不是电机效率。
  它把铜损、铁损、开关损、机械损全算进一个数里了。逐场的 1/η 在 1.24–1.58 之间，
  所以用固定系数做跨场次比较时记得这个散布。
* **这是本车这一套标定的经验式，不是物理定律**：换电机、换逆变器、换母线电压平台
  都要重新拟合。`python tools\bus_current.py` 跑一遍就有新系数。

## 复现

```powershell
# 前提：这些场次里母线 + 四条电机都在（i3pro pair 合出来的那些）

# 换数据目录
```
