# MoTeC `.ld` 文件格式逆向记录

本文件记录 `i3pro` 原生解析器所依据的二进制结构。所有结论都是在**车队自己的 8 个真实
C125 日志**上逐字节验证得到的，并与 MoTeC 自己导出的 CSV 做了逐样本对照（见
`tools/verify_ld_vs_csv.py`）。

## 1. 文件头（64 字节，小端）

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| `0x00` | u32 | 头部长度，恒为 `0x40` |
| `0x04` | u32 | Event 记录偏移 |
| `0x08` | u32 | 通道记录链表头（第一条通道记录的偏移） |
| `0x0c` | u32 | 通道记录区结束 = 第一个采样块起始 |
| `0x24` | u32 | 辅助块指针（未使用，内容为空） |
| `0x2c` | u32 | 辅助块指针（未使用，内容为空） |
| `0x40`… | 字符串 | 设备名（`C125`）、日期 `dd/mm/yyyy`、时间 `hh:mm:ss`、固件版本等 |

## 2. Event 记录（位于 `header[0x04]`）

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| `0x00` | u32 | 事件哈希 |
| `0x04` | u32 | venue 指针（多数日志为空字符串，值恒为 `0x28a`） |
| `0x08` | u32 | 会话哈希 |
| `0x0c` | u16 | 默认采样率（本车队日志为 100） |
| `0x10` | u32 | details 指针 |
| `0x14` | char[32] | 事件名，例如 `E27_Dashboard_AutoX_20260902_pjgps` |

## 3. 通道记录（124 字节，双向链表）

从 `header[0x08]` 开始沿 `next` 指针遍历，`next == 0` 结束。链表顺序就是 i2 Pro /
CSV 中的通道顺序。

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| `0x00` | u32 | prev 指针 |
| `0x04` | u32 | next 指针 |
| `0x08` | u32 | 数据块起始偏移 |
| `0x0c` | u32 | 采样点数 |
| `0x10` | u16 | 通道 ID |
| `0x12` | u16 | 数据类型（`3` = int16，`5` = int32） |
| `0x14` | u16 | 每采样字节数（`2` 或 `4`） |
| `0x16` | u16 | 采样率 \[Hz] |
| `0x18` | u16 | shift（本车队全部日志恒为 0） |
| `0x1a` | u16 | 乘数 multiplier |
| `0x1c` | u16 | 除数 divider |
| `0x1e` | **i16** | 小数位 decimals（**有符号**，`0xffff` 表示 −1） |
| `0x20` | char[32] | 通道名 |
| `0x40` | char[8] | 短名（i2 图例显示名） |
| `0x48` | char[24] | 单位 |
| `0x54` / `0x58` | u32/i32 | 显示范围上限 / 下限（按缩放后的整数单位） |
| `0x6c` | u32 | 通道哈希 |

### 数值换算

```
工程值 = 原始整数 × multiplier ÷ divider ÷ 10^decimals
```

`decimals` 必须按**有符号 16 位**读取：

* `decimals = 2` → 原始 9 表示 0.09 G（`G Force Lat`）
* `decimals = 7` → 原始 346756583 表示 34.6756583°（`GPS Latitude`）
* `decimals = -1`（文件里是 `0xffff`）→ ×10，例如 `Timestamp MTI` 的原始值单位是
  10 µs，逆变器 `TargetVelocity` 的乘数 6 表示 rpm

### 数据区

各通道数据块按链表顺序**紧邻存放**，从 `header[0x0c]` 开始到文件尾结束：

```
offset(next channel) == offset(prev channel) + sample_count × bytes_per_sample
```

因此 8 个日志中「链表遍历 + 连续性校验」都可以作为解析正确性的自检。

## 4. `.ldx` 配套文件

`.ldx` 是 i2 Pro 的图层/标记文件（XML）：记录 `Total Laps`、`Fastest Time` 等
Details，以及 Beacons 标记组。**注意：本车队的 `.ldx` 全部显示 `Total Laps = 1`，
因为 C125 的 beacon 输入未接线**，所以 i2 Pro 里也无法切圈——这正是 `i3pro` 改用
GPS 切圈的原因。

## 5. 与 CSV 导出的差异

MoTeC 导出 CSV 时：

* 会把慢通道（10/20/50 Hz）**重采样**到主采样率（100 Hz），因此这些通道不能按索引
  对齐比较；
* 会丢掉 `Beacon` 通道（标记改为 marker）；
* 会把 `(LoRes)` 后缀去掉（`Susp Pos FR (LoRes)` → `Susp Pos FR`）。
